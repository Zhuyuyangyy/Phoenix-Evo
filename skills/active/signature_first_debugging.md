## When to Use
当遇到 TypeError: xxx() takes N positional arguments but M were given、AttributeError: 'xxx' object has no attribute 'yyy'、ImportError: cannot import name 'xxx' from 'yyy' 等接口级别错误时，在调用接口前先读函数签名或类定义，从签名本身反推正确用法。

## Procedure
1. **遇到接口错误立即查签名**：不要反复猜测参数，用 inspect.signature() 或 read_file 读源码
2. **Python 对象**：execute_code(code=import inspect; print(inspect.signature(func_or_class)))
3. **外部工具/API**：用 tool_schema 中的 parameters 定义对照自己传的参数名
4. **匹配签名后再调用**：发现参数数量/名称不匹配时，用 named args 而非位置 args 提高可读性
5. **如果签名本身有问题**（参数名拼写错误、类型注解错误），记录下来作为潜在的代码 bug 反馈

## Failure Cases
| 错误阶段 | 错误信息 | 修复策略 |
| -------- | -------- | -------- |
| TypeError 参数数量不匹配 | takes N positional arguments but M were given | 用 named kwargs 而非位置传参，对照 signature() 逐一核对 |
| AttributeError 属性不存在 | 'xxx' object has no attribute 'yyy' | 先 hasattr(obj, 'yyy') 检查，再读源码确认是否存在别名或拼写差异 |
| ImportError 导入失败 | cannot import name 'xxx' from 'yyy' | 用 help(yyy) 或 __all__ 查可用名称，确认大小写或版本差异 |
| 函数签名与文档不符 | 文档说支持某参数但报 TypeError | 以运行时 signature() 为准，文档可能过时 |

## Safety Note
[low_risk] 纯诊断方法，不涉及写入操作。signature-first 策略可以把接口错误调试时间从 10+ 分钟缩短到 1 分钟以内。
