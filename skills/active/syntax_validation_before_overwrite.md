## When to Use
在覆写任何 Python/Vue/HTML/JS 文本文件之前，用 ast.parse() 或 py_compile 先验证语法合法性，发现 SyntaxError 立即停止覆写操作，防止把文件修成损坏状态。

## Procedure
1. **覆写前先 parse 验证**：
   execute_code(code="import ast; ast.parse(open('目标文件路径').read())")
2. **如果 parse 失败**（文件已损坏）：先从备份恢复，或用 /tmp/ 版本重新写
3. **写临时文件时同步验证**：写到 /tmp/ 时就做一次 py_compile，确认无错后再迁移
4. **批量覆写前抽检**：多个文件覆写前先抽 1-2 个验证语法，防止连带损坏
5. **覆写后二次验证**：完成迁移后再读一次，确认文件内容完整（非截断、无 null 字节）

## Failure Cases
| 错误阶段 | 错误信息 | 修复策略 |
| -------- | -------- | -------- |
| 源文件本身已损坏 | SyntaxError: unexpected EOF in multi-line statement | 先恢复备份，再重新写入合法内容，不要直接覆写损坏文件 |
| 写入过程被截断 | 写入后文件长度异常 | 读取文件内容，确认长度符合预期，如有异常从备份恢复 |
| 编码错误导致 parse 失败 | UnicodeDecodeError | 用 encoding='utf-8' 或 'gbk' 显式指定编码重读，确认文件编码 |
| py_compile 静默通过但运行报错 | ImportError 运行时才出现 | parse 验证语法，import 验证模块级别依赖，分两步检查 |
